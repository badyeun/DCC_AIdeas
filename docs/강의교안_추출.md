•

•

•

웹 크롤링
•
BeautifulSoup, Selenium 활용
•
저작권·robots.txt 반드시 확인
직접 수집 / 라벨링
•
설문, 실험, 어노테이션 툴 활용
•
비용이 크지만 맞춤 데이터 확보 가능

===== p7 =====
④ 모델 학습 — 데이터에서 패턴을 찾다
모델은 데이터 속 패턴을 수식으로 압축한다. 학습이란 그 수식의 파라미터를 최적화하는 과정이다.
모델 유형 선택 가이드
지도학습 (Supervised)
분류: 로지스틱 회귀, 랜덤 포레스트, XGBoost, 신경망
회귀: 선형 회귀, SVR, 딥러닝
비지도학습 (Unsupervised)
클러스터링: K-Means, DBSCAN
차원 축소: PCA, t-SNE
딥러닝 (Deep Learning)
CNN: 이미지 분류
RNN/LSTM: 시계열, 텍스트
Transformer: 자연어 처리
학습 핵심 개념
•
손실 함수 (Loss): 예측 오차 측정
•
경사 하강법 (Gradient Descent): 오차를 줄
이는 방향으로 파라미터 업데이트
•
에포크 (Epoch): 전체 데이터를 한 번 학습하
는 단위
•
배치 (Batch): 한 번에 처리하는 데이터 묶음
•
학습률 (Learning Rate): 업데이트 보폭 크기
 과적합 vs 과소적합
•
과적합 (Overfitting): 훈련 데이터에만 잘 맞고 새 데이터에 실패 → 드롭아웃, 정규화로 해결
•
과소적합 (Underfitting): 모델이 너무 단순해 패턴을 못 잡음 → 모델 복잡도 증가

⑤ 평가 및 배포 — 모델을 세상에 내보내다
좋은 모델은 실험실에서 끝나지 않는다. 실제 환경에서 작동해야 비로소 가치를 만든다.
평가 지표 (Metrics)
정확도 (Accuracy)
전체 중 맞춘 비율. 클래스 불균형 시 주의
정밀도 / 재현율 (Precision / Recall)
스팸 탐지, 의료 진단 등 비대칭 문제에 핵심
F1-Score
정밀도와 재현율의 조화 평균
AUC-ROC
이진 분류 모델의 전반적 성능 측정
배포 방식
•
REST API: Flask, FastAPI로 모델 서빙
•
클라우드 배포: AWS SageMaker, GCP Vertex 
AI, Azure ML
•
엣지 배포: 모바일/IoT 기기에 경량화 모델 탑재 
(TFLite, ONNX)
•
배치 처리: 주기적으로 대량 데이터 예측 (야간 배
치)
배포 후 모니터링 중요성
•
데이터 드리프트(Data Drift): 실제 데이터 분포가 학습 데이터와 달라지는 현상
•
모델 성능 저하 감지 → 재학습(Retraining) 주기 설정
•
A/B 테스트로 신규 모델 점진적 적용

인공지능의 역사 ① — AI의 탄생 (1950년대 · 1960~70년대)
AI의 씨앗은 1950년대에 뿌려졌다. 초기의 낙관은 곧 첫 번째 겨울을 맞이했다.
 1950년대 — AI의 탄생
•
앨런 튜링, "Computing Machinery and Intelligence" 논문 발표 
(1950)
•
튜링 테스트: 기계가 인간처럼 대화할 수 있는지 판별하는 기준 제시
•
다트머스 회의(1956, 존 매카시 주도): "Artificial Intelligence" 용어 
최초 공식 사용
•
Logic Theorist(1956): 수학 정리를 자동 증명한 최초의 AI 프로그램
•
대표 인물: 앨런 튜링, 존 매카시, 마빈 민스키, 클로드 섀넌
 1960~70년대 — 낙관과 첫 번째 AI 겨울
•
ELIZA 챗봇(1966, MIT): 최초의 자연어 처리 프로그램 — 심리 상담사 역할 
모방
•
SHAKEY 로봇(1969, SRI): 최초의 자율 이동 로봇 — 환경 인식 후 경로 계
획
•
퍼셉트론 한계 증명(Minsky & Papert, 1969): XOR 문제 해결 불가 → 연구 
자금 급감
•
첫 번째 AI 겨울(1974~1980): 영국 Lighthill 보고서로 정부 지원 대폭 삭감
•
"AI는 불가능하다"는 비관론 확산 — 연구자들 대거 이탈

인공지능의 역사 ② — 전문가 시스템과 규칙 기반 AI (1980년대 
· 1997)
기업들이 AI를 처음 도입한 시대. 규칙 기반 AI의 전성기와 한계가 동시에 드러났다.
 1980년대 — 전문가 시스템 붐
•
규칙 기반 전문가 시스템(Expert System): "IF-THEN" 규칙으로 전문가 지식
을 코드화
•
XCON(DEC사, 1980): VAX 컴퓨터 구성 자동화 → 연간 $4천만 절감, 정확
도 95%
•
MYCIN(스탠퍼드): 혈액 감염 진단 AI — 전문의 수준의 정확도 달성
•
일본 제5세대 컴퓨터 프로젝트(1982): 국가 주도 AI 개발 — 서방 국가 긴장
•
두 번째 AI 겨울(1987~1993): 하드웨어 한계·유지비 급증·기대 미달로 재침
체
 1997 — 딥블루 vs 카스파로프
•
IBM 딥블루, 세계 체스 챔피언 가리 카스파로프 격파 (3.5:2.5, 6게임)
•
초당 2억 개 체스 포지션 계산 — 전용 하드웨어 + 체스 전문가 지식 결합
•
1996년 1차전에서는 카스파로프가 승리(4:2) → 1년 후 재대결에서 역전
•
"기계가 인간 지능을 넘을 수 있다"는 인식 전환 — 전 세계 1억 명 시청
•
규칙 기반 AI의 정점이자 한계: 체스 외 범용 지능은 여전히 불가능

인공지능의 역사 ③ — 딥러닝 혁명 (2012 · 2016~2017)
GPU와 빅데이터가 만나 딥러닝이 폭발했다. 알파고는 AI가 인간의 직관 영역까지 넘어섰음을 증명했다.
 2012 — 딥러닝 혁명
•
AlexNet(제프리 힌튼 팀), ImageNet 대회 오류율 26% → 15.3%로 
대폭 감소
•
2위와의 격차 10%p 이상 — 딥러닝이 기존 방법론을 압도적으로 능가
•
NVIDIA GPU 병렬 연산 활용 → 대규모 신경망 학습 비용 혁신적 절감
•
제프리 힌튼, 얀 르쿤, 요슈아 벤지오 — "딥러닝 3인방" (2018 ACM 
튜링상 수상)
•
컴퓨터 비전·음성 인식·자연어 처리 전 분야 AI 성능 급등
 2016~2017 — 알파고 & Transformer
•
알파고(DeepMind, 2016): 이세돌 9단 4:1 격파 — "바둑은 AI가 못 이
긴다"는 통념 붕괴
•
강화학습 + 딥러닝 결합 — 인간의 직관적 판단 영역까지 AI가 진입
•
AlphaGo Zero(2017): 인간 기보 없이 자기 대국만으로 3일 만에 알파
고 초월
•
Transformer 아키텍처 등장(2017, Google, "Attention is All You 
Need")
•
자율주행·의료 영상 진단·실시간 번역 AI 상용화 본격 시작

생성형 AI의 데이터 이해: GAN 사례
AI는 원본 데이터의 분포를 학습해 새로운 데이터를 생성함. 대표 사례가 GAN
임.
GAN은 진짜와 가짜를 구별하는 판별자와, 진짜 같은 이미지를 만드는 생성자가 
경쟁하며 학습함.
이미지는 픽셀 값으로 이루어진 숫자 행렬이며, GAN은 그 행렬의 패턴과 분포를 
모방해 실제 같은 결과를 만들어냄.

Epoch 1
완전한 랜덤 노이즈. 픽셀이 무작위로 분포됨
Epoch 10
희미한 윤곽 등장. 형태가 보이기 시작함
Epoch 50

Epoch 200+

데이터 분포 이해 — 개요
데이터가 어떤 분포를 따르는지 파악하면 올바른 모델과 전처리 방법을 선택할 수 있다.
분포란 무엇인가?
•
데이터가 어떤 값에 얼마나 자주 나타나는지를 나타내는 함
수
•
확률 밀도 함수(PDF): 연속형 데이터의 분포
•
확률 질량 함수(PMF): 이산형 데이터의 분포
•
누적 분포 함수(CDF): P(X ≤ x)를 나타냄
분포를 알아야 하는 이유
•
이상치 탐지: 분포 꼬리 부분의 값 식별
•
모델 선택: 분포 가정에 맞는 알고리즘 선택
•
전처리 방향: 정규화·로그 변환 필요 여부 판단
•
가설 검정: 통계적 유의성 판단의 기반
연속형 분포
정규분포, 균등분포, 지수분포, 베타분포, 감마분포

===== p32 =====
연속형 분포 ① — 정규분포 & 균등분포
가장 자주 마주치는 두 연속형 분포. 자연 현상과 무작위 샘플링의 기반이다.
정규분포 (Normal Distribution)
자연 현상(키, 몸무게, 측정 오차)에서 가장 흔히 나타나는 종 모양 분포. 평
균(μ)과 표준편차(σ)로 완전히 정의됨.
•
평균 = 중앙값 = 최빈값 (완전 대칭)
•
68-95-99.7 규칙: ±1σ에 68%, ±2σ에 95%, ±3σ에 99.7%
•
표준 정규분포: μ=0, σ=1로 표준화한 형태
AI에서의 활용
•
가중치 초기화 (Xavier, He 초기화)
•
잔차(Residual) 분포 확인
•
가우시안 노이즈 추가 (데이터 증강)
균등분포 (Uniform Distribution)
모든 구간에서 동일한 확률을 가지는 분포. 연속형(Continuous)과 이산
형(Discrete) 모두 존재함.
연속 균등분포
•
평균: (a+b)/2
•
분산: (b-a)²/12
AI에서의 활용
•
난수 생성 및 무작위 샘플링
•
하이퍼파라미터 탐색 (Random Search)
•
드롭아웃 마스크 생성
===== p33 =====
연속형 분포 ② — 지수분포 & 베타분포
사건 간격과 확률 자체를 모델링할 때 핵심이 되는 분포들이다.
지수분포 (Exponential Distribution)
사건과 사건 사이의 대기 시간을 모델링하는 분포. 포아송 과정에서 자연스
럽게 도출됨. 항상 양수 값만 가짐.
•
λ: 단위 시간당 평균 발생 횟수 (rate parameter)
•
평균: 1/λ, 분산: 1/λ²
•
무기억성(Memoryless): P(X > s+t | X > s) = P(X > t)
AI에서의 활용
•
서버 요청 간격, 장비 고장 시간 모델링
•
생존 분석 (Survival Analysis)
•
이상 탐지: 비정상적으로 짧은 간격 탐지
베타분포 (Beta Distribution)
0과 1 사이의 확률 값 자체를 모델링하는 분포. 두 형상 파라미터 α, β로 
다양한 모양을 표현함.
•
α=β=1이면 균등분포와 동일
•
α>β이면 1에 치우침, α<β이면 0에 치우침
•
평균: α/(α+β)
AI에서의 활용
•
베이지안 추론에서 사전 분포(Prior)로 활용
•
A/B 테스트 전환율 모델링
•
드롭아웃 비율, 앙상블 가중치 모델링
===== p34 =====
이산형 분포 ① — 이항분포 & 포아송분포
성공/실패 횟수와 단위 시간 내 발생 횟수를 모델링하는 가장 중요한 이산 분포들이다.
이항분포 (Binomial Distribution)
n번의 독립 시행에서 성공 확률이 p일 때, 성공 횟수 X의 분포. 베르누이 시
행의 합으로 구성됨.
•
평균: np, 분산: np(1-p)
•
n=1이면 베르누이 분포와 동일
•
n이 크고 p가 작으면 포아송 분포로 근사 가능
AI에서의 활용
•
이진 분류 모델의 출력 확률 모델링
•
클래스 불균형 데이터 생성 (오버샘플링)
•
교차 검증 성능 통계 검정
포아송분포 (Poisson Distribution)
단위 시간(또는 공간)에 평균 λ번 발생하는 사건의 횟수 분포. 희귀 사건 
모델링에 적합함.
•
평균 = 분산 = λ (포아송 분포의 특징)
•
λ가 크면 정규분포로 근사 가능
•
사건들이 서로 독립이어야 함
AI에서의 활용
•
클릭 수, 구매 횟수 등 카운트 데이터 모델링
•
이상 탐지: 예상보다 많은 이벤트 발생 감지
•
자연어 처리: 단어 빈도 모델링
===== p35 =====
이산형 분포 ② — 기하분포 & 음이항분포
첫 번째 성공까지의 시행 횟수와 k번째 성공까지의 시행 횟수를 모델링한다.
기하분포 (Geometric Distribution)
성공 확률 p인 베르누이 시행을 반복할 때, 첫 번째 성공이 나올 때까지의 
시행 횟수 X의 분포.
•
평균: 1/p, 분산: (1-p)/p²
•
무기억성(Memoryless) 성질 보유
•
이산형 분포 중 유일하게 무기억성을 가짐
AI에서의 활용
•
첫 번째 이상 탐지까지의 시간 모델링
•
강화학습: 에피소드 길이 분포 모델링
•
재시도 횟수 기반 시스템 신뢰성 분석
음이항분포 (Negative Binomial Distribution)
성공 확률 p인 베르누이 시행에서 r번째 성공이 나올 때까지의 총 시행 횟
수 분포. 기하분포의 일반화.
•
r=1이면 기하분포와 동일
•
평균: r/p, 분산: r(1-p)/p²
•
분산 > 평균 → 과산포(Overdispersion) 데이터에 적합
AI에서의 활용
•
포아송 분포로 설명 안 되는 과산포 카운트 데이터
•
텍스트 데이터의 단어 빈도 모델링 (NLP)
•
의료 데이터: 재입원 횟수, 재발 횟수 예측
===== p36 =====
분포 형태 분석 — 왜도 & 첨도
분포의 모양을 수치로 요약하면 전처리 방향과 모델 선택의 단서를 얻을 수 있다.
왜도 (Skewness) — 비대칭성
분포가 평균을 기준으로 얼마나 비대칭인지를 나타내는 지표.
왜도 = 0
완전 대칭 (정규분포)
왜도 > 0 (양의 왜도)
오른쪽 꼬리가 긴 분포. 소득, 자산 
데이터에 흔함. 로그 변환 권장.
왜도 < 0 (음의 왜도)
왼쪽 꼬리가 긴 분포. 시험 점수(상한 효과)에 흔함.
첨도 (Kurtosis) — 뾰족함
분포의 꼬리가 얼마나 두껍고 중심이 얼마나 뾰족한지를 나타내는 지표.
첨도 = 3 (정규분포 기준)
Mesokurtic: 정규분포와 동일한 꼬
리 두께
첨도 > 3 (Leptokurtic)
뾰족하고 꼬리가 두꺼움. 이상치 
多. 금융 수익률에 흔함.
첨도 < 3 (Platykurtic)
납작하고 꼬리가 얇음. 균등분포에 가까운 형태.
실전 팁: |왜도| > 1이면 로그 변환(np.log1p), |왜도| > 2이면 Box-Cox 변환을 우선 고려함. 첨도가 높으면 이상치 처리 후 재확인 필요.

EDA에서 왜도·첨도가 중요한 이유
왜도와 첨도는 단순한 통계 수치가 아니다. EDA의 모든 후속 결정을 좌우하는 나침반이다.
① 전처리 방향 결정
왜도·첨도를 확인하면 어떤 변환이 필요한지 즉시 판단할 수 있다.
|왜도| < 0.5 → 변환 불필요
정규분포에 가까움. StandardScaler 바로 적용 
가능.
0.5 ≤ |왜도| < 1 → 로그 변환 고려
np.log1p(x) 적용 후 왜도 재확인.
|왜도| ≥ 1 또는 첨도 높음 → 강한 변환 필요
Box-Cox, Yeo-Johnson 변환 또는 이상치 제거 선행.
② 모델 선택 기준
분포 형태는 어떤 알고리즘이 잘 작동할지를 결정한다.
•
선형 회귀 / 로지스틱 회귀: 피처가 정규분포에 가까울수록 성능 안정적
•
트리 기반 모델 (랜덤 포레스트, XGBoost): 왜도·첨도에 상대적으로 강건함. 변환 없이도 작동 가능.
•
신경망: 정규화 필수. 왜도가 크면 학습 불안정 (Gradient Exploding 위험)
•
나이브 베이즈: 정규분포 가정 → 왜도 높으면 성능 급락
③ 이상치 탐지 신호
•
첨도 > 5: 꼬리가 두꺼워 극단값 존재 가능성 높음 → IQR/Z-Score 탐지 즉시 수행
•
왜도 > 2: 한쪽 방향으로 극단값이 분포를 왜곡 중 → 박스플롯으로 시각 확인
EDA 실전 순서
01
df.describe()로 기초 통계 확인
02
df.skew() / df.kurtosis()로 왜도·첨도 수치 확인
03
히스토그램 + KDE로 분포 시각화
04
왜도 기준으로 변환 전략 결정 후 재확인

===== p173 =====
Mel-spectrogram, MFCC
멜스펙트로그램(Mel Spectrogram)
오디오신호의스펙트로그램을멜척도로변환한것이다. 여기서멜척도란실제주파수를인간의청각인식에더가깝게매핑하는
비선형척도이다. 인간의청각은높은주파수에서넓은주파수간격을더넓게인식하는특성이있는데, 쉽게말해낮은주파수에서는
미세한차이를잘감지하지만높은주파수에서는덜민감하게인식한다는것이다. 멜척도는이를반영하여낮은주파수(약20 ~
500Hz라고한다)에서더세밀한해상도를제공하고, 높은주파수에서는주파수간격을넓게설정하여상대적으로낮은해상도를
제공한다.
MFCC(Mel-Frequency Capstral Coefficients)
멜스펙트럼(Mel Spectrum)을기반으로하는오디오처리기법이다. 오디오신호의짧은구간(프레임)에대한멜스펙트로그램을
사용하여DCT(Discrete Cosine Transform)을통해더욱압축한형태로변환하는데, 이과정을통해중요한특성을추출하게
된다. 결과적으로MFCC를통해오디오데이터의feature를뽑아벡터화할수있게된다. MFCC는음성인식에서굉장히
유용하게쓰인다.
- Mel: 사람의주파수지각특성을반영
- Frequency: 주파수정보를사용
- Cepstral: Log spectrum을다시변환한표현
- Coefficient: 변환결과로얻은계수

3. 모달리티(Modality) 융합(Fusion) 종류
- 서로다른두데이터를합치는(Fusion) 데에는대표적으로세가지전략이있습니다.
1)Early Fusion
- 방법: 각데이터를전처리한후, 모델에입력하기전입력단에서바로합쳐버리는방식입니다.
2)Late Fusion
- 방법: 각데이터에대해독립적인모델을따로따로통과시킨후, 각모델이내놓은최종결과(예측값)를합치는방식입니다.
3)Joint or Intermediate Fusion
- 방법: 각데이터가별도의인코더(Encoder)를통과하며특징(Feature)을추출한뒤, 모델의중간레이어에서이특징들을합치는
방식입니다. (가장많이사용되는방식)

- 입력: RGB 컬러이미지+ Depth (깊이) 이미지

- 목표: 컬러정보만으로는알기어려운객체의3차원형태와거리를깊이정보로보강하여, 더정확한장면이해, 객체분할, 자율주행등에활용합니다.

1. Noise augmentation은Log-Mel spectrogram의일부주파수영역을제거하는방법이며, SNR이높을수록잡음이강하다.
2. wav2vec 2.0은Log-Mel spectrogram을Patch로나누어Transformer에입력하고, AST는Raw waveform의일부
구간을Masking하여학습한다.
3. Audio augmentation은실제환경에서발생할수있는변화를학습데이터에적용하는방법이며, wav2vec 2.0은주로
Raw waveform을, AST는주로Log-Mel spectrogram을입력으로사용한다.
4. Time masking과Frequency masking은Validation 데이터에무작위로적용하여평가데이터의다양성을높이는것이
일반적이다.

1.
Spectrogram의일부주파수영역을가리는것은Frequency masking입니다. Noise
