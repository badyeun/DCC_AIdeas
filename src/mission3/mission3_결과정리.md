# Mission 3 결과 정리

119 신고 전사에서 9개 증상을 예측. 평가는 Macro F1, 판정 임계값은 **전 증상 0.5 고정**.

- 평가: Training 29,200통화를 그룹 분할한 **자체검증 5,840통화**
- **공식 Validation은 학습·선택·보정 어디에도 쓰지 않았습니다**
- 모델 입력: `utterances[].text`만. 화자·시각·성별·주소는 읽지 않습니다

---

## 1. 최종 성적

공식 Validation 3,640통화에서 **실측**했습니다.

| | Macro F1 |
|---|---:|
| **제출 (이질 11개 앙상블, 임계값 0.5)** | **0.65658** |
| ver4, 0.5 고정 + 보정 재적합 | 0.65591 |
| ver4, 증상별 임계값 (현 규칙 위반) | 0.65648 |

**규칙을 지킨 상태에서 ver4보다 +0.0007, 규칙을 어긴 ver4보다도 +0.0001입니다.**
임계값을 조작하지 않고 그 수준에 도달했습니다.

> 두 후보의 차이(+0.0007)는 부트스트랩 2,000회에서 95% 구간
> [−0.0044, +0.0059], 이긴 비율 59%로 **통계적으로 구분되지 않습니다.**
> 둘 다 내도 실질적으로 같은 성적입니다.

증상별:

| 증상 | 제출 | ver4(0.5) | 차이 |
|---|---:|---:|---:|
| 복통 | 0.8265 | 0.8232 | +0.0033 |
| 열상 | 0.8879 | 0.8912 | −0.0033 |
| 고열 | 0.7025 | 0.7024 | +0.0001 |
| 호흡곤란 | 0.6647 | 0.6754 | −0.0107 |
| 어지러움 | 0.6637 | 0.6618 | +0.0019 |
| 구토 | 0.6118 | 0.6057 | +0.0061 |
| 전신쇠약 | 0.5875 | 0.5989 | −0.0115 |
| 두통 | 0.5500 | 0.5457 | +0.0043 |
| **오심** | **0.4146** | 0.3988 | **+0.0158** |

> 참고: Training 내부 홀드아웃에서는 0.6467이었습니다. 공식 Validation이
> 0.009 쉬웠다는 뜻이고, ver4도 같은 방향입니다(내부 0.6597 → 0.6565).
> **홀드아웃 점수를 Validation 예상치로 그대로 쓰면 안 됩니다.**

## 2. 효과가 있었던 것

| 방법 | ΔMacro F1 | 근거 |
|---|---:|---|
| **앙상블 (확률 단순 평균)** | **+0.0089** | 크기별 150개 부분집합의 평균 |
| **전체 데이터 학습** | **+0.0010** | 데이터 크기 곡선, 최상단 구간 기울기 |

| 멤버 수 | 4 | 8 | 10 | 12 | 16 | 23 |
|---|---:|---:|---:|---:|---:|---:|

### 같은 크기라면 이질 구성이 낫습니다

| 구성 (6개) | F1 (+TF-IDF) |
|---|---:|

**비슷하게 좋으면서 달라야** 합니다.

## 4. 왜 더 안 오르는가 — 데이터 분석

### 4.1 임계값 0.5 고정은 거의 공짜였습니다

증상별로 임계값을 자유롭게 골랐다면 0.6441 → 0.6503, **+0.0062**가 전부입니다.
게다가 그 임계값은 채점한 데이터에서 고른 값이라 실제로는 더 작습니다.
단조 보정은 순위를 못 바꾸므로 **확률 보정으로 얻을 수 있는 것도 이게 전부**입니다.

### 4.2 모델은 전사에서 읽을 수 있는 것을 거의 다 읽습니다

놓친 정답(FN)과 잘못 짚은 것(FP)에 전사 근거가 있는지:

| 증상 | FN 수 | FN에 표현 있음 | FP 수 | FP에 표현 있음 |
|---|---:|---:|---:|---:|
| 구토 | 404 | **1.5%** | 280 | 50.4% |
| 두통 | 309 | 10.4% | 240 | 56.2% |
| 호흡곤란 | 210 | 33.3% | 313 | **86.9%** |

**양쪽 다 어노테이션 행동입니다.** 구토는 놓친 404건 중 6건에만 구토 표현이
있습니다 — 읽고도 못 맞힌 게 아니라 읽을 게 없습니다. 반대로 호흡곤란 FP의
87%에 "숨"이 나옵니다 — 모델은 단어를 봤는데 어노테이터가 안 붙였습니다.

### 4.3 오심만 질적으로 다릅니다

표현이 있는 통화 안에서 라벨 유무를 구분할 수 있는가:

| 증상 | 조건부 AUC | | 증상 | 조건부 AUC |
|---|---:|---|---|---:|
| 열상 | 0.980 | | 두통 | 0.777 |
| 고열 | 0.940 | | 어지러움 | 0.774 |
| 복통 | 0.897 | | 구토 | 0.726 |
| 호흡곤란 | 0.871 | | **오심** | **0.567** |
| 전신쇠약 | 0.842 | | | |

오심 AUC 0.777은 거의 전부 "이게 구토·어지러움 통화인가"를 맞히는 데서
나옵니다. **그 안에서 오심이 추가로 붙었는지는 동전던지기(0.567)입니다.**

| 전사에 있는 표현 | 건수 | 오심 양성률 |
|---|---:|---:|
| 메스 | 90 | 63.3% |
| 미식 | 112 | 63.4% |
| 울렁 | 161 | 50.3% |
| 토했 | 116 | 25.9% |

**"메스꺼워요"라고 또박또박 말해도 오심 라벨은 63%만 붙습니다.**

오심이 전사 밖 정보로 설명되는지도 확인했습니다 — triage·urgencyLevel·
sentiment 등 메타데이터로는 AUC 0.616(텍스트보다 낮음), 월별 드리프트 없음,
발화자(접수자/신고자) 무관. **답이 어디에도 없습니다.**

### 4.4 두통의 모호함은 머리 외상에서 옵니다

| 전사 패턴 | 건수 | 두통 | 열상 |
|---|---:|---:|---:|
| 머리 + 아프/아파 | 1,280 | **65.9%** | 1.3% |
| 머리 + 피/출혈 | 645 | 9.9% | **89.6%** |
| **머리 + 다치/부딪** | 507 | **28.0%** | **55.2%** |

두통의 핵심 표현은 양성률 66~70%로 충분히 강합니다. 흔들리는 건 외상입니다 —
같은 "머리를 부딪혔어요"가 어떤 날은 두통, 어떤 날은 열상입니다.

## 5. 측정의 한계 (중요)

| 각 설정의 실행 수 | 탐지 가능 최소 효과 |
|---:|---:|
| 1 | 0.0077 |
| **3 (주로 사용)** | **0.0044** |
| 10 | 0.0024 |
| 40 | 0.0012 |

잡음은 seed(표준편차 0.0023)와 평가(0.0015)에서 옵니다.

**"효과 없음"으로 적은 것 중 상당수는 "이 설계로 못 쟀다"입니다.** 헤드 혼합·
학습률·TF-IDF는 +0.0012~0.0014로 보이는데 확인에 각각 30~40 seed가 필요합니다.
TF-IDF와 이질 구성만 별도 검증(반분 80회 / 무작위 200회)을 거쳤기에 "확정"이라
적을 수 있었습니다.

반대로 **큰 효과는 전부 찾았습니다.** 앙상블(+0.0089)과 데이터 크기(50%→100% 구간 전체로는 +0.0096)는
seed 1~4개면 잡히는 크기입니다. **0.005 이상짜리는 남아 있지 않을 가능성이
높습니다.**

## 7. 규칙 준수

- 서울 Training만 사용, 외부 데이터 없음
- 공식 Validation은 학습·선택·보정에 미사용
- 입력은 `utterances[].text`만
- 대상 외 증상은 라벨 목록에서 제거(샘플은 유지)
- **판정 임계값 전 증상 0.5** — 증상별 임계값 없음
- 상용 AI API 미사용, 오픈소스 사전학습 체크포인트만
- 도메인 적응 MLM도 Training 전사만 사용(자체검증분 제외)
