5. 실행 시간과 자동 배치

전체 노트북 실행: 5시간 32분 42초.
전체 Training 학습 자체: 4시간 56분 6초.
GPU: NVIDIA L4. 최종 1 epoch에서 29,200개 모두 처리, overflow retry 0회.
시간 예산: None. 예산 때문에 시작을 거부하거나 중단하는 옵션은 꺼져 있었다.

Qwen 자동 배치 측정:
batch 8: 1.009 examples/s
batch 4: 1.280 examples/s
batch 2: 1.599 examples/s (선택)
batch 1: 1.113 examples/s
선택한 batch 2와 gradient accumulation 8을 사용해 유효 batch 16을 유지했다.
큰 배치가 더 빠를 것이라는 가정 대신 실제 측정에서 가장 빠른 설정을 골랐다.

앞서 안내한 약 8시간대는 안전계수와 저장 여유가 포함된 권장 예산이며 실제 소요 시간과 다르다.
학습 입력 29,200개 중 1,024 token 한도를 넘은 것은 4개였다. 학습 데이터의 광범위한
입력 잘림이 이번 병목이라는 근거는 없다. Validation의 길이별 오류는 별도 검증하지 않았다.
