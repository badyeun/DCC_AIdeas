결론
- 4,000개, Qwen/KLUE 각 3epoch 선별 실험은 정상 완료했다. 최종 제출용 전체 학습은 아니다.
- 같은 Training 내부 development 4,380개에서 Qwen2epoch + KLUE3epoch의 고정 1:1 확률 평균 Macro F1는 0.64618767다.
- 기존 ver25 예비 실험 최고 Qwen 0.63124028보다 0.01494739(약 1.49%p) 높다.
- Qwen 단독의 추가 학습 효과는 확인되지 않았다. KLUE 개선과 두 모델의 서로 다른 오답이 앙상블 개선에 기여했다.
- 이 결과로 공식 Validation 0.7 달성이나 친구 모델 추월을 판단할 수 없다. 이번 실행은 confirmation/공식 Validation을 평가하지 않았다.

- Qwen batch2 × 누적8, KLUE batch8 × 누적2를 자동 선택했다. 유효 batch는 모두16이다.

앙상블의 보완성과 불확실성
- 새 KLUE와 Qwen의 판정이 다른2,212건 중 고정 평균이1,321건(59.72%)을 맞혔다.
- 두 모델의 공통 오답은3,262건이다. 앙상블의 전체 이진 오답은4,153건으로, 이전 pilot Qwen의4,354건보다201건 적다.
- 기존 최고 pilot Qwen 대비 Macro F1 차이의 2,000회 paired95% 구간: [+0.009085, +0.021157].
- 같은 development를 epoch/후보 선택에 재사용한 구간이다. 선택 편향, 반복 실험, 학습 seed 변동은 포함하지 않아 독립 검증 성능의 보장으로 쓸 수 없다.

다음 실험 권고 (이번 요청에서는 새 학습 코드나 실행을 시작하지 않음)
1. 현재 앙상블을 비교 기준으로 보관한다. Qwen2/KLUE3의 4,000개 최고 epoch를 전체 학습의 최적값으로 바로 옮기지 않는다.
2. 같은4,000개·seed42·3epoch·WBCE·분할을 유지하고 Qwen optimizer 학습률만0.3배로 낮춘 비교를 우선한다: LoRA1e-4→3e-5, head3e-4→9e-5. 이는 원인 분리를 위한 가설이며 확인된 최적값이 아니다.
3. 단독 F1/AP/검증loss와 같은 KLUE 대비 고정1:1 앙상블을 함께 비교한다. 사후 임계값이나 혼합 비율 탐색은 하지 않는다. 현재와 비슷한 처리량이면 준비 포함 약3시간 규모다.
4. 개선이 없으면 학습 횟수 증가를 반복하지 않고 증상 이름·정의를 연결하는 학습 구조를 소규모로 시험한다. 구조 변경의 성능·추론 비용은 아직 미검증이다.
5. 유망한 설정을 더 큰 fit에서 확인한 뒤 동결하고 confirmation, 전체 refit, 공식 Validation 순으로 진행한다. 이미 관찰한 평가셋의 한계를 계속 기록한다.

8시간 조건에서의 확대 비용 (실제 확장 실행이 아닌 단순 비례 추정)
- fit20,440개 Qwen2epoch + development2회: 7시간 15분 46초.

- 위 값에는 설치·다운로드·배치 측정·KLUE·저장·재로딩·안전 여유가 빠져 있다. 전체2epoch는 같은L4의8시간 한도에 들어오지 않는다.
- 더 빠른GPU 실측 또는 안전한 이어 학습 구현이 먼저 필요하다. ver26를 다시 실행하는 것은 중단점 이어 학습이 아니다.
