결론
- 정상 완료했지만 학습률 0.3배 조건을 채택할 근거는 없다. 내부 development 기준 최고 비교 모델은 ver26을 유지한다.
- 주 비교 Macro F1: 0.64618767 → 0.63992006, 차이 -0.00626761.
- 사전 지정 paired bootstrap 500회 95% 구간: [-0.01064119, -0.00152053]. 이번 저장 예측에서 하락을 지지한다.
- 같은 검증셋의 반복 사용, 최고 epoch 선택, 학습 seed 변동은 이 구간에 반영되지 않는다. 모든 조건에서 저학습률이 나쁘다는 결론은 아니다.
- 4,000개 학습 / 내부 development 4,380개 평가다. confirmation과 공식 Validation은 평가하지 않았고 최종 제출 모델도 아니다.
- 친구의 공식 Validation 점수와 이 내부 점수를 직접 비교하지 않는다. 공식 F1 0.7 초과는 아직 확인되지 않았다.

완료와 비교 조건
- 실행 시간 2시간 52분 55초, NVIDIA L4, 각 모델 3 epoch·750 optimizer update·overflow retry 0.
- Qwen batch2×누적8, KLUE batch8×누적2로 ver26과 동일하다. 공개 모델 revision·라이브러리 버전·분할·정답·subset도 확인했다.
- Qwen 학습률만 LoRA 1e-4→3e-5, head 3e-4→9e-5로 변경했다. 다른 설정 차이는 버전·경로·시간 관리 필드다.
- screening_complete는 저장·비교 완료 표시다. screening_selection의 improved=true는 새 KLUE 단독보다 앙상블이 높다는 뜻이며 ver26보다 개선됐다는 뜻이 아니다.

0.7을 향한 다음 실험: ver28 제안 (구현/학습하지 않음)
1. ver26 학습률로 복귀하고 Qwen의 증상별 표현만 변경한다.
   현재: 통화 뒤 일반 지시문 마지막 위치의 표현 하나에서 9개 증상을 예측.
   제안: 통화 뒤에 고정된 9개 증상 질문을 붙이고 각 질문 끝의 표현에서 해당 증상을 예측.
   통화당 모델 forward 1회, 기존 9×hidden head 크기를 유지할 수 있다. 답변 생성이나 정답을 입력에 넣지 않는다.
   LoRA 1e-4, head 3e-4, r16, 동일 4,000개·seed42·3epoch·weighted BCE·고정 0.5 판정을 유지한다.
   KLUE는 저장된 ver26 예측을 고정하여 구조 변경 효과를 비교한다. 이 비교만으로 배포 가능한 새 앙상블이 만들어지는 것은 아니다.
   질문 순서·위치·라벨 매핑·잘림·padding을 검증하고, 저장 후 재로딩 예측과 모든 epoch 예측을 남긴다.
   질문 추가로 실제 통화 부분이 더 잘리지 않도록 통화 토큰 예산을 맞춘다. 추가 길이와 속도는 기록한다.
   증상별 표현 연구를 참고한 가설이다. 이번 결과가 마지막 토큰 표현의 병목을 입증한 것은 아니다.
2. 기존 주 비교와 같은 확대 기준을 적용한다.
   ver26 0.64618767 대비 +0.005 이상(0.65118767 이상)이고 paired 95% 하한>0이면 확대 후보다.
   단독 F1/AP, 약한 증상의 정밀도·재현율, 공통 오답도 함께 보고 어떤 문제가 개선됐는지 설명한다.
   통과하더라도 0.7 달성 판정이 아니다. 이 재사용 development 기준은 실험 자원을 배분하기 위한 선별이다.
3. 유망하면 별도 실행에서 8,000개로 확대한다.
   더 큰 fit에서 학습 횟수·설정을 확인한 뒤 조건을 동결하고, 남겨둔 confirmation을 한 번 확인한다.
   이후 전체 Training refit과 공식 Validation 평가로 0.7 초과 여부를 확인한다. 전체 학습 자체가 상승을 보장하지 않는다.
4. 구조 변경도 실패하면 같은 LR/epoch 탐색을 반복하지 않는다.
   원본 Training의 약한 네 증상에서 공통 FN/FP를 표본 검토해 질문·부정·과거 상태·간접 표현 등 실제 오류 범주를 확인한다.
   검토 근거에 따라 다음 학습 가설을 정한다. 현재 분석만으로 라벨 오류나 잡음 제거의 효과를 확정할 수 없다.

필요한 개선 규모와 시간
- 기준 0.64618767에서 0.7까지 Macro +0.05381233이 필요하다. 나머지 다섯 증상이 유지돼도 약한 네 증상의 F1을 각각 +0.10 올리면 0.690632에 그친다.
- 0.7 초과에는 여러 약한 증상의 큰 개선 또는 더 넓은 전반적 개선이 필요하다. 새 구조의 성공 확률이나 최종 점수를 현재 자료로 보장할 수 없다.
- 제안한 4,000개 구조 실험은 L4 약 3~4시간을 계획 범위로 잡되, 실제 새 구조의 배치 속도를 측정해 8시간 안에 들어올 때만 3epoch를 시작한다.
- 1.35배 안전 여유와 마지막 25분 저장 예약을 유지한다. 질문 추가의 GPU 속도는 아직 측정하지 않았다.
- ver27 실측 선형 추정: 기존 구조 Qwen 8,000개×3epoch+검증3회 = 4시간 40분 2초.
- ver27 실측 선형 추정: 기존 구조 Qwen fit20,440개×2epoch+검증2회 = 7시간 18분 53초.
- ver27 실측 선형 추정: 기존 구조 Qwen 전체29,200개×2epoch 학습만 = 9시간 51분 59초.
- 선형 추정은 준비·배치 측정·저장·재로딩·길이 변화·안전 여유를 제외한다. 전체 2epoch는 현재 L4의 8시간 한도에 들어오지 않으므로 더 빠른 GPU 실측 또는 별도 이어 학습 구현이 필요하다.
