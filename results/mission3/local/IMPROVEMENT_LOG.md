# Mission 3 개선 기록

시도할 때마다 **무엇을 바꿨고 / 얼마나 달라졌고 / 쓸 만한지**를 한 줄로 남깁니다.

- 평가: Training 29,200개를 그룹 분할한 **자체검증 5,840통화**. 공식 Validation은 쓰지 않습니다.
- 임계값: 전 증상 **0.5 고정** (주최 측 안내).
- 기준선: 단일 모델 평균 **0.63706**, 최고 단일 0.64016.
- 참고로 ver4의 공식 Validation 점수는 0.6566이지만 **평가 대상이 달라 직접 비교 불가**입니다.

## 상세

### 1. 텍스트 정규화 — 효과 없음

"메스껍다/매스껍다/울렁거리다"를 하나로 묶고, "토할 거 같다"처럼 표기가 흔들리는 것을 통일. 필러("어", "음") 제거.

| 모델 | seed | 원문 | 정규화 | 차이 |
|---|---:|---:|---:|---:|
| base | 42 | 0.63772 | 0.63980 | +0.0021 |
| base | 1 | 0.63543 | 0.63670 | +0.0013 |
| base | 7 | 0.63829 | 0.63576 | −0.0025 |
| large | 42 | 0.64016 | 0.63798 | −0.0022 |

**2승 2패, 평균 −0.0003.** seed 편차(0.0046)의 10분의 1이라 측정 불가. 동의어만 따로 떼도 +0.0004로 같습니다.

> 주의: 처음엔 "+0.0067, 3전 3승"으로 나왔는데, 검증 세트 분할 버그(전처리별로 다른 시험지) 때문이었습니다. 고치니 사라졌습니다.

### 2. 모델 크기 — 거의 무의미

large 단일 0.64016 vs base 3개 평균 0.63715. +0.0030인데 seed 편차 안입니다. 게다가 **base 4개 앙상블(0.64470)이 large 단일보다 높습니다.** 학습 시간은 49분 vs 14분.

### 3. 앙상블 — 유일하게 확실한 개선

| 모델 수 | 평균 Macro F1 | 기준 대비 |
|---:|---:|---:|
| 1 | 0.63706 | — |
| 2 | 0.64213 | +0.0051 |
| 4 | 0.64470 | +0.0076 |
| 9 | **0.64593** | **+0.0089** |
| 11 | 0.64563 | +0.0086 |

330~462개 조합의 **평균**이라 운이 아닌 기댓값입니다. 9개에서 포화합니다.

### 4. 최소 1개 증상 강제 출력 — 손해

빈 예측에 가장 확률 높은 증상 하나를 넣는 후처리. **11개 실행 전부 손해**, 평균 −0.0008.

ver4에서는 이득(+0.004~0.006)이었는데 반대입니다. 빈 예측이 적을수록 남은 건 정말 애매한 통화라, 찍으면 오답이 됩니다. 게다가 출제 PDF 9쪽에 **증상 개수가 0개일 수 있다**고 명시돼 있어 원리적으로도 위험합니다.

### 5. epoch 수 — 3이 정점

6 epoch 실행 곡선: 0.614 → 0.624 → **0.634** → 0.625 → 0.621 → 0.616. loss는 0.52 → 0.27로 계속 내려가는데 점수는 반대로 갑니다. ver3가 15 epoch 돌려 얻은 결론과 같습니다.

### 6. 백본 다양화 — 진행 중

**가설**: 지금 앙상블은 전부 klue/roberta-base의 seed만 다른 것이라 9개에서 포화했다. 사전학습 말뭉치가 다른 모델은 오류 패턴이 달라 더 멀리 간다.

시험 대상: KcELECTRA-v2022, KoELECTRA-v3, klue/bert-base, kcbert-base. 앞의 둘은 댓글·구어체로 학습돼 119 통화에 가깝습니다.

**판정 기준**: 같은 크기(4개)에서 *백본 4종 앙상블* vs *roberta-base seed 4개 앙상블*.

**판정: ✗ 쓰지 않음.** seed 다양성보다 나쁩니다.

| 앙상블 3개 | Macro F1 |
|---|---:|
| klue/roberta-base seed 3개 | **0.64131** |
| 백본 3종 | 0.63721 (−0.0041) |

개별 성능: bert-base 0.63415 / KcELECTRA 0.62761 / KoELECTRA 0.62375 (기준 0.63772).
전체 앙상블에 넣어도 손해입니다 (klue 계열 11개 0.64563 → 14개 0.64384).

**왜 안 되는지**: 예측 불일치율을 재보니 다른 백본끼리 3.86~4.52%인데, 같은 모델 seed끼리도 3.10~3.64%입니다. **다양성은 0.8%p 느는데 개별 성능은 0.4~1.4%p 떨어집니다.** 품질 손실이 다양성 이득을 잡아먹습니다.

구어체 사전학습(KcELECTRA·KcBERT)이 119 통화에 유리할 거라 봤는데 반대였습니다. KoELECTRA가 낮은 것은 ver7 결과와 일치합니다.

> kcbert-base는 최대 입력 300토큰 제한으로 실패 — 512로 넣을 수 없어 제외.

**교훈**: 앙상블 멤버를 늘릴 땐 *다르기만* 해선 안 되고 *비슷하게 좋으면서* 달라야 합니다.

### 7. 증상별 attention 헤드 — 진행 중

**가설**: 지금은 토큰 표현을 단순 평균해서 9개 증상이 같은 문장 벡터를 공유한다. ver4는 증상마다 attention을 따로 둬서 "열상"은 "피가 나요"를, "오심"은 다른 곳을 보게 한다. 이게 ver4에 있고 내 파이프라인에 없던 가장 큰 구조 차이다.

구현: `scores = queries(tanh(project(H)))` → 토큰 축 softmax → 증상별 문맥 벡터 → 증상별 선형 출력. 파라미터는 20만 개(+0.2%)만 늘어납니다.

**판정 기준**: 같은 seed(42/1/7), 같은 holdout, 같은 원문에서 mean pooling과 짝비교.

**판정: 단독 ✗ (+0.0001) / 앙상블 재료로는 ○ (+0.0014)**

| seed | mean | attention | 차이 |
|---:|---:|---:|---:|
| 42 | 0.63772 | 0.63405 | −0.0037 |
| 1 | 0.63543 | 0.63725 | +0.0018 |
| 7 | 0.63829 | 0.64053 | +0.0022 |

단독 평균 +0.0001로 잡음 안입니다. 그런데 **섞으면 오릅니다.**

| 앙상블 3개 | Macro F1 |
|---|---:|
| mean 3개 | 0.64131 |
| attention 3개 | 0.64127 |
| **혼합 3개** | **0.64266** (+0.0014) |
| 6개 전부 | **0.64445** |

불일치율은 3.357% → 3.498%로 **0.14%p** 늘었을 뿐인데 효과가 났습니다. 실험 6의 백본 다양화는 0.8%p나 늘렸는데 실패했죠. **차이는 개별 성능**입니다 (attention 0.63728 ≈ mean 0.63715 / 백본들은 0.4~1.4%p 낮음).

**권장**: 앙상블을 만들 때 한 헤드로만 채우지 말고 두 헤드를 섞을 것.

### 8. 긴 통화 슬라이딩 윈도우 — 재보고 접음 (GPU 미사용)

지금 512토큰에서 자릅니다. ver4는 윈도우를 썼으니 격차인데, **실제 영향을 먼저 쟀습니다.**

| | |
|---|---:|
| 512토큰 초과 | 788개 (**2.70%**) |
| 512 이하 통화 점수 | 0.63760 |
| 512 초과 통화 점수 | 0.62575 |

3%의 통화가 0.012 낮을 뿐이라, **완벽히 고쳐도 전체 기여는 0.0004 수준**입니다. 한 시간짜리 GPU 실험을 5분 계산으로 대체했습니다.

**교훈**: 구현하기 전에 상한부터 계산할 것.

### 9. pos_weight — 진행 중

**가설**: 임계값이 0.5로 고정된 지금, 확률이 0.5의 어느 쪽에 놓일지를 정하는 건 학습 단계의 `pos_weight`뿐이다. 예전엔 보정이 임계값을 옮겨서(오심 0.411) 맞췄는데 그 길이 막혔다. 현재 값은 ver4에서 물려받은 것이고 0.5 체제에 맞춰 고른 적이 없다.

확인해 보니 `sqrt3/5/8`은 전부 같은 값입니다 — 최대 sqrt 비율이 3.03(두통)이라 clip이 안 걸립니다. 실제로 다른 건 셋뿐입니다.

| 방식 | 가중치 범위 |
|---|---|
| `none` | 1.00 |
| `sqrt` (현재) | 1.82 ~ 3.03 |
| `full` | 3.31 ~ 9.17 |

**판정 기준**: seed 42/1/7 × 3방식, 같은 holdout. 오심 정밀도(0.32)가 개선되는지도 함께 봅니다.

**판정: ✗ 현재 설정이 이미 최적.**

| pos_weight | 평균 가중치 | seed 42 |
|---|---:|---:|
| none | 1.00 | 0.61931 |
| **sqrt (현재)** | **2.4** | **0.63772** ← 정점 |
| pow065 | 3.3 | 0.63277 |
| pow080 | 4.4 | 0.61992 |

역U자이고 정점이 현재값입니다. "임계값 0.5 고정이 pos_weight에 빈틈을 만든다"는 가설은 틀렸습니다. ver4에서 물려받은 값이 이미 맞았습니다.

부수 관찰: `none`에서는 **최소 1개 강제가 처음으로 이득**이었습니다(+0.0045). 가중치가 약하면 모델이 소극적이 되어 빈 예측이 늘고, 그때는 찍는 게 낫습니다. 후처리의 유불리는 pos_weight에 달려 있습니다.

### 10. 학습된 앙상블 결합 (스태킹) — ✗

holdout을 반으로 갈라 2,920개로 결합을 배우고 나머지 2,920개로 채점.

| 결합 방식 | Macro F1 |
|---|---:|
| **단순 평균** | **0.64204** |
| 증상별 로지스틱 | 0.60901 (−0.033) |
| 전 증상 공통 가중치 | 0.62805 (−0.014) |
| 상위 절반만 평균 | 0.64019 (−0.002) |

**왜 지는지**: 로지스틱 결합은 출력 분포를 재보정하는데, **임계값이 0.5에 묶여 있으면 그 재보정이 곧 위험**입니다. 단순 평균은 멤버들의 보정 상태를 보존합니다.

**이게 반복되는 패턴입니다.** 0.5 고정 체제에서는 출력 분포를 건드리는 시도가 전부 불리했습니다 — 스태킹, pos_weight 변경, 최소 1개 강제 모두.

## 2차 캠페인 (10/1~)

"모델 쪽은 소진됐다"고 했던 제 판단이 성급했습니다. **학습률을 한 번도 안 건드렸는데** 그보다 덜 중요한 pos_weight는 5가지나 훑었습니다. 순서가 거꾸로였습니다.

### 11. 학습률 — ○ 기존 설정이 정점에서 벗어나 있었음

| 학습률 | epoch | Macro F1 |
|---|---:|---:|
| 1e-5 | 3 | 0.63411 |
| 1e-5 | 5 | 0.63559 |
| **2e-5** | **3** | **0.64055** ← 정점 |
| 2e-5 | 4 | 0.63592 |
| 3e-5 | 3 | 0.63772 (기존) |
| 5e-5 | 3 | 0.63489 |
| 8e-5 | 3 | 0.63032 |

역U자 정점이 **2e-5**이고, 지금까지 쓰던 3e-5는 **+0.0028 손해**였습니다. epoch은 모든 학습률에서 3이 맞았습니다 (낮은 학습률에 5 epoch을 줘도 정점은 epoch 3).

**단, seed 1개짜리라 잡음(0.005) 안입니다.** seed 1·7로 재확인 중 — 확인 전에는 이 위에 아무것도 쌓지 않습니다.

**교훈**: 하이퍼파라미터는 영향이 큰 것부터. 학습률을 빼놓고 다른 걸 먼저 훑은 게 실수였습니다.

**검증 결과: △ 방향은 일관되나 크기는 잡음 수준.**

| seed | 3e-5 (기존) | 2e-5 | 차이 |
|---|---:|---:|---:|
| 42 | 0.63772 | 0.64055 | +0.0028 |
| 1 | 0.63543 | 0.63579 | +0.0004 |
| 7 | 0.63829 | 0.63910 | +0.0008 |
| | | **평균** | **+0.0013** |

3전 3승이지만 평균 +0.0013으로 seed 편차(0.0029~0.0048) 안입니다. 처음 본 +0.0028은 seed 42가 유독 좋았던 것이고 실제 기대값은 절반 이하입니다.

학습률을 안 훑은 건 방법론적 실수가 맞지만, **메워 보니 +0.0013짜리**였습니다. "소진됐다"는 판단이 성급했던 것도 맞고, 큰 게 숨어 있던 것도 아닙니다.

### 12. 배깅 (멤버마다 다른 80% 부분집합) — ✗

| | 개별 평균 | 불일치율 | 3개 앙상블 |
|---|---:|---:|---:|
| 배깅 | 0.63650 | 2.738% | 0.64074 |
| seed 다양성 | 0.63848 | 2.792% | 0.64075 |
| 차이 | −0.0020 | **−0.054%** | **−0.00001** |

**배깅이 다양성을 전혀 늘리지 못했습니다.** 오히려 seed 변경보다 미세하게 덜 다양합니다.

가설이 틀린 지점: "서로 다른 데이터를 보면 더 다르게 틀릴 것"이라 봤는데, 18,688개와 23,360개가 같은 분포에서 나온 이상 모델이 거의 같은 함수로 수렴합니다. **무작위 초기화와 배치 순서만으로 다양성이 이미 포화**돼 있습니다.

따라서 ver4의 5-fold가 잘 됐던 건 배깅이라서가 아니라 **그냥 앙상블이라서**입니다.

**교훈**: 이 과제에서 앙상블 다양성은 늘릴 방법이 없어 보입니다. 백본을 바꿔도(실험 6), 데이터를 바꿔도(실험 12) 안 늘어납니다. 유일하게 늘어난 건 헤드 구조 변경(실험 7, +0.14%p)이었고 그마저 작았습니다.

### 13. 데이터 크기 곡선 — ○ 전체 데이터 학습은 +0.004 예상

| 학습 데이터 | 통화 수 | Macro F1 |
|---|---:|---:|
| 50% | 11,680 | 0.62758 |
| 65% | 15,184 | 0.63064 |
| 80% | 18,688 | 0.63650 |
| 100% (현재 train split) | 23,360 | 0.63848 |

로그 선형 회귀 기울기 **log 단위당 +0.0168**. Training 전체 29,200개(현재의 125%)로 외삽하면 **+0.004** (잡음 감안 범위 +0.002~+0.005).

**이미 쓸 수 있는 데이터를 안 쓰고 있던 것**이라 사실상 공짜입니다. 지금은 자체검증용으로 20%를 떼어놔서 23,360개만 씁니다.

단, 29,200개 전부로 학습하면 **로컬 검증 세트가 사라집니다.** 측정이 아니라 이 외삽으로 정당화하고 최종 제출 모델에만 적용하는 게 맞습니다.

### 14. EMA (가중치 이동평균) — △ 평균 무효, 분산은 4배 감소

| seed | EMA 없음 | EMA 0.999 | 차이 |
|---|---:|---:|---:|
| 42 | 0.64055 | 0.63878 | −0.0018 |
| 1 | 0.63579 | 0.63767 | +0.0019 |
| 7 | 0.63910 | 0.63833 | −0.0008 |
| | | **평균** | **−0.0002** |

평균은 0인데 **seed 편차가 0.0048 → 0.0011로 4배 줄었습니다.**

최종 제출처럼 한 번만 쓰는 모델에는 "평균 같고 분산 작은 쪽"이 합리적입니다. 운 나쁜 seed를 뽑을 위험이 줄어듭니다. 반면 **앙상블에는 불리할 수 있습니다** — 멤버가 서로 비슷해지면 다양성이 줄어듭니다.

> 관찰: EMA는 epoch 1에서 빈 예측이 3,428개(59%)까지 튑니다. 감쇠 0.999면 그림자 가중치가 초기화 상태에서 따라잡는 데 수천 스텝이 걸려, 3 epoch 학습에는 과하게 느린 설정입니다.

### 15. 손실함수 ASL / Focal — ✗

| seed | BCE | ASL | Focal |
|---|---:|---:|---:|
| 42 | 0.64055 | 0.63297 | 0.63870 |
| 1 | 0.63579 | 0.63077 | 0.63409 |
| **평균 차이** | — | **−0.0063** | **−0.0018** |

ASL은 잡음을 넘는 차이로 집니다. Focal은 거의 안 집니다.

**차이의 원인**: ASL은 pos_weight를 **대체**하고, Focal은 **유지**합니다. 실험 9에서 pos_weight가 뚜렷한 역U자 정점을 갖는 걸 확인했는데, 그걸 빼버린 ASL이 크게 지고 유지한 Focal은 거의 안 집니다.

**pos_weight가 이 과제의 핵심 설정**이고, 손실 모양 변경은 그 위의 장식입니다.

> ver6이 동결 특징 위에서 "A~C 손실 교체가 기존보다 낮다"며 유보했던 항목인데, 전체 미세조정에서 제대로 시험해도 같은 결론입니다. 유보 하나 정리.

# 2라운드 — 라벨 쪽 공략 (2026-10-02)

## 0. 지표 교체 시도 — **실패. F1@0.5를 그대로 씁니다**

처음에 "AP의 seed 편차가 F1@0.5의 1/5.9라 더 좋은 판정 기준"이라고 적었습니다.
**틀렸습니다.** 두 가지를 잘못했습니다.

1. 1/5.9는 **한 묶음**(mean lr2e-5)에서만 나온 값이었습니다. 세 묶음 평균을
   내면 AP 편차 0.00188 대 F1 편차 0.00470으로 2.5배일 뿐입니다.
2. 더 중요한 건 조용함이 아니라 **재려는 것과 같이 움직이는가**입니다.
   단일 실행 42개에서 **AP와 F1@0.5의 상관은 0.207**입니다.

| 지표 | F1@0.5와의 상관 | seed 잡음 | 유용도(상관/잡음) |
|---|---:|---:|---:|
| **F1@0.5** | 1.000 | 0.00470 | 213 |
| 순위 상한 (증상별 최적 임계 F1) | 0.372 | **0.00103** | **363** |
| 평균 AP | 0.207 | 0.00188 | 110 |
| R-precision | 0.404 | 0.00386 | 105 |

**AP는 F1@0.5보다 오히려 못한 기준입니다.** AP는 순위 전체(꼬리 포함)를 재는데
F1@0.5는 임계선 근처만 보기 때문입니다. 반증 사례가 바로 있습니다:
attention 헤드는 mean보다 AP가 +0.0053 높은데 **순위 상한 F1은 0.64750으로
mean의 0.64939보다 낮습니다.**

**결론: 판정은 F1@0.5로, 짝지은 다중 seed로 합니다.** '순위 상한'만 보조로
씁니다(유용도 1.7배). 1라운드에서 "측정 불가"로 버린 판정들은 그대로 유효합니다.

## 17. 임계값 0.5 고정의 실제 비용 — **+0.0062가 전부**

증상별 임계값을 자유롭게 골랐다면 Macro F1 0.64411 → 0.65029. 게다가 그 임계값은
채점한 바로 그 데이터에서 고른 값이라 실제로는 더 작습니다.

**교훈:** 0.5 고정으로 잃은 건 seed 편차 수준입니다. 더 중요한 건, 단조 보정은
순위를 못 바꾸므로 **확률 보정으로 얻을 수 있는 것도 이 +0.0062가 전부**라는 점.
남은 지렛대는 순위(ranking)의 질 하나뿐입니다.

## 18. 모델은 전 구간 과신하지만 고치면 안 됩니다

**교훈:** 과신은 버그가 아니라 "학습으로 구현한 임계값 이동"입니다. #17과 합치면

| 증상별 9개 | +0.00081 | 0.00012 | 76% |

자유도를 9개로 늘리면 **오히려 나빠집니다.** 게다가 고른 가중치가 9개 중
8개에서 0.10으로 수렴합니다(복통만 0.00) — 증상별로 다를 이유 자체가 약합니다.

**교훈:** 자유도 9개는 전부 잡음을 흡수합니다. 전역 0.10 하나가 더 좋습니다.
덤으로 [docs/멘토_질문.md](../../../docs/멘토_질문.md) Q1(증상별 혼합 비율)이
실용적으로는 무의미해집니다 — 규정상 허용되더라도 **쓰면 손해**입니다.

# 2라운드 학습 실험 (라벨 구조를 모델에 주입)

판정 기준: ΔF1@0.5 (잡음 0.0047, seed 짝지음). 보조로 Δ순위상한 (잡음 0.0010).
기준선: lr 2e-5 · 3 epoch · seed 42/1/7 평균 **F1 0.63848 · 순위상한 0.64520**.

## 26. 로짓 잔차 혼합층 (`--label_corr`) — ✗

9개 로짓 위에 0으로 초기화한 선형 혼합층. 오심이 구토·어지러움 로짓을
참조할 수 있게 합니다.

| seed | F1@0.5 | ΔF1 | 순위상한 | Δ순위상한 |
|---|---:|---:|---:|---:|
| 42 | 0.63281 | −0.00774 | 0.64511 | +0.00014 |

**패턴이 선명합니다: 순위 상한은 그대로인데 F1@0.5만 떨어집니다.** 순위를
개선한 게 아니라 0.5 대비 위치만 밀었습니다. 1라운드에서 스태킹(−0.033),
pos_weight 변경, 최소1개 강제가 전부 졌던 것과 정확히 같은 기제입니다.

**왜 안 되는지**: 공동출현 정보는 모델이 **이미 최대한 쓰고 있습니다.**
사후 규칙으로 구토/어지러움 통화에서 오심을 끄면 오심 F1이 0.38 → 0.17로
무너집니다(상세: [data_analysis_label_side.md](../../../src/mission3/data_analysis_label_side.md)).
명시적 혼합층은 쓸 정보를 더 주는 게 아니라 과적합할 여지를 더 줍니다.

## 27. 증상별 손실 가중치 — ✗ 두 변형 모두

Macro F1은 9개를 똑같이 세는데 BCE는 빈도대로 셉니다. 증상별로 손실을
재가중하면(양·음 **같은 배율**이라 경계는 안 움직임) 희귀 증상에 용량이
더 갈 것이라는 가설.

| 변형 | 가중치 | ΔF1 | Δ순위상한 |
|---|---|---:|---:|
| `invfreq` (1/√빈도) | 0.80~1.23 | −0.00151 | −0.00066 |
| `custom` (오심·두통·전신쇠약 ×1.6) | 0.83~1.33 | −0.00213 | −0.00116 |

약한 쪽도 강한 쪽도 음수입니다. 순위 상한까지 내려갔으니 "0.5 위치" 문제도
아니고 **순위 자체가 나빠집니다.**

**교훈**: 약한 증상이 약한 건 **용량이 부족해서가 아니라 타깃이 잡음이기
때문**입니다. 용량을 더 줘도 외울 게 잡음뿐입니다.

### 여기까지의 공통 패턴

지금까지 라벨 쪽에서 시도한 것 중 **라벨 사이에 노력을 재분배하는 조작은
전부 졌습니다** — pos_weight(1라운드 5가지), 증상별 손실 가중치(2가지),
로짓 혼합층, 스태킹, 증상별 혼합 비율.

9개 라벨은 용량을 놓고 경쟁하는 관계가 아닙니다. 다음 실험(증류·오버샘플링·
R-Drop)은 **재분배가 아니라 타깃의 성질이나 데이터 분포 자체**를 바꾸는
것이라 기제가 다릅니다.

## 28. **자기 증류 — 순위를 움직인 첫 실험** (판정 진행 중)

학습 분할을 4등분하고, 각 조각을 보지 않은 모델이 그 조각의 확률을 예측
(`--folds 4 --fold i`). 이어 붙인 OOF 확률을 정답과 섞어 타깃으로 씁니다
(`타깃 = (1−α)·정답 + α·교사확률`). 모든 샘플을 같은 규칙으로 다루므로
"라벨에 따라 다른 전처리"가 아닙니다.

교사(OOF Macro F1 0.642)가 스스로 말해 주는 것:

| 집단 | 오심 소프트값 (정답=1) | (정답=0) | 분리도 |
|---|---:|---:|---:|
| 구토 통화 안 | 0.449 | 0.396 | **0.053** |
| 단독 통화 | 0.311 | 0.150 | 0.161 |

구토 통화 안에서는 정답이 뭐든 0.42쯤을 냅니다. 앞서 잰 조건부 AUC 0.617이
교사 출력에 그대로 나타납니다.

**결과 (seed 42):**

| 실행 | F1@0.5 | Δ | 순위상한 | Δ | 예측수 | 최적 공통임계 |
|---|---:|---:|---:|---:|---:|---:|
| 기준선 | 0.64055 | — | 0.64497 | — | 8,347 | 0.51 |
| 증류 α0.3 | 0.63248 | −0.0081 | **0.64667** | **+0.0017** | 9,583 | **0.61** |
| 증류 α0.5 | 0.62658 | −0.0140 | **0.64667** | **+0.0017** | 9,970 | 0.65 |

(정답은 8,305건)

**순위 상한을 잡음(0.0010) 위로 올린 첫 실험입니다.** 지금까지 20여 개 중
처음입니다. 그런데 F1@0.5는 떨어집니다.

**원인** (처음엔 반대로 적었다가 숫자 보고 고침): 소프트 타깃이 음성 타깃을
0에서 들어올려(α×교사확률) 출력을 가운데로 압축하는데, `pos_weight=sqrt`가
이미 부풀리고 있어 **이중으로 밀립니다.** 오심은 1,162건 예측(정답 675).

**보정 계산**: `pos_weight`를 w1→w2로 바꾸면 결정 경계가 log(w2/w1)만큼
움직입니다. 필요한 건 실효 임계 0.5→0.61, 즉 로짓 −0.44.
sqrt 평균 2.38 → pow025 평균 1.54면 log(1.54/2.38) = **−0.44**. 정확히 맞습니다.
→ phase 6에서 `--pos_weight pow025` 조합 + `pow025` 단독 대조군을 돌립니다.

**주의**: 최적 임계값끼리 비교하면 증류 0.64206 대 기준선 0.64074로 **+0.0013,
F1 잡음(0.0047) 안입니다.** 순위상한 신호(+0.0017 / 잡음 0.0010)가 더 믿을
만하지만 크지 않습니다. 2 seed 확인 전에는 판정하지 않습니다.

**α는 0.3이 정점**입니다. 0.5로 올리면 순위상한은 그대로인데 과다예측만 늘어
F1이 더 떨어집니다.

있습니다. **R-precision**(각 증상에서 정답 개수만큼 상위를 뽑은 적중률)은
임계값 위치와 완전히 무관하므로 교차 확인에 씁니다.

기준선 3 seed 평균 R-precision **0.63574** (seed 편차 0.00306)

| 증류 α0.5 | +0.00223 | +0.003 | −0.003 | +0.003 |
| 증류 α0.7 | +0.00362 | +0.009 | +0.004 | +0.008 |
| 로짓 혼합층 | −0.00085 | −0.002 | −0.004 | −0.001 |

# 36. 이 설계가 잴 수 있는 최소 효과 — 캠페인 전체의 해석을 바꿉니다

37개쯤 실험했는데 앙상블 말고는 전부 "잡음 안"이었습니다. **효과가 없어서인지

잡음은 두 갈래입니다.

| 출처 | 표준편차 |

## 관측된 효과 크기와 대조

| 효과 | 크기 | 검정력 80%에 필요한 seed |
|---|---:|---:|
| 앙상블 1개 → 9개 | +0.0089 | **1** |
| 전체 데이터 학습 (외삽) | +0.0040 | 4 |
| 헤드 혼합 | +0.0014 | **30** |
| 학습률 3e-5 → 2e-5 | +0.0013 | **35** |
| TF-IDF 혼합 | +0.0012 | **41** |

**"잡음 안"의 상당수는 "효과가 없다"가 아니라 "이 설계로 못 잰다"였습니다.**
헤드 혼합·학습률·TF-IDF는 +0.0012~0.0014로 보이는데, 확인에 각각 30~40 seed가
필요합니다. 저는 2~3개로 판정했습니다.

TF-IDF만 **반분 검증 80회**로 따로 확인했기에 유일하게 "확정"이라 말할 수
있었습니다. 같은 수고를 다른 후보에 들이지 않은 것은 제 선택이고, 그
비대칭은 명시해 둬야 합니다.

**반대로, 큰 효과는 전부 이미 찾았습니다.** 앙상블(+0.0089)과 전체 데이터
학습(+0.0040)은 seed 1~4개면 잡히는 크기라 놓칠 수 없었습니다.
**0.005 이상짜리는 남아 있지 않을 가능성이 높습니다.**

|---|---:|---:|---|

| CLS 헤드 | −0.0015 | **0.0158** | +0.0006 |
| dropout 0.2 | −0.0016 | 0.0063 | −0.0005 |

**학습 과정의 미세 조정은 모델을 거의 안 바꾸고(불일치율 0.006~0.014),
크게 바꾸는 조정은 모델을 나쁘게 만듭니다(maxlen256).** 품질을 지키면서
0.015 이상 다르게 만드는 것은 **입력(정규화)·구조(헤드)·사전학습(DAPT)**
수준에서만 나옵니다.

제출 구성이 정확히 그 셋으로 이뤄져 있습니다.

# 46. roberta-large, 끝까지 — 음수 확정. 그리고 제 비판이 틀렸습니다

## 무엇을 잘못 봤나

3 epoch 실행의 상승은 **학습률 스케줄이 3 epoch 에 맞춰 0 으로 수렴하면서
마지막 epoch 에 생기는 효과**였습니다. 스케줄을 6 epoch 로 늘리자 같은
지점의 실효 학습률이 높아져 과적합으로 들어갔습니다. 곡선의 모양을
"데이터가 더 필요하다는 신호"로 읽었는데, 실은 **스케줄의 모양**이었습니다.

1라운드 #5 에 base 의 6 epoch 곡선이 이미 있었습니다:
0.614 → 0.624 → **0.634** → 0.625 → 0.621 → 0.616. **같은 모양입니다.**
그 데이터를 갖고 있으면서 "large 는 다를 것"이라고 가정했습니다.

**#40 의 원래 판단("base 와 동점이고 3.7배 비싸다")이 옳았고, 그것을
공정하지 않다고 한 제 비판이 틀렸습니다.** 남은 2 seed(3.7시간)는
중단했습니다 — 곡선이 명확하고 base 에서 이미 본 패턴입니다.

# 47. KcELECTRA 재검증 — 학습률 빈틈을 메웠으나 미달

"구어체 전용 모델이니 대화 데이터에 유리하지 않겠나"는 가설. 1라운드에서
lr 3e-5 로만 쟀고, 나중에 2e-5 가 더 낫다고 밝혀졌으므로 빈틈이 실재했습니다.

판정 기준을 **결과를 보기 전에** 정했습니다: (1) 단독이 lr3e-5 를 넘을 것,
(2) 11개 앙상블 추가 효과가 2 seed 평균 +0.001 초과일 것.

| | 단독 F1 | 불일치율 | 앙상블 추가 |
|---|---:|---:|---:|
| lr 3e-5 s42 (기존) | 0.62761 | 0.0460 | −0.00059 |
| lr 2e-5 s42 | 0.62613 | 0.0474 | −0.00061 |
| lr 2e-5 s1 | 0.62742 | 0.0456 | +0.00032 |
| **2 seed 평균** | **0.62677** | | **−0.00015** |

**두 단계 모두 미달.** 학습률을 바꾸니 오히려 낮아졌습니다.

## 가설이 왜 틀렸나 — 세 갈래로 확인

| 검증 | 결과 |
|---|---|
| KcELECTRA (학습률 2종, 3회) | −0.010 ~ −0.014 |
| 다른 한국어 백본 4종 | 전부 klue/roberta-base 이하 |
| **전사 29,200건 직접 도메인 적응** | perplexity 4.86→3.24, 성능 불변 |

세 번째가 결정적입니다. 말뭉치를 **이 데이터 그 자체**로 맞춰도 안 올랐으므로,
사전학습 말뭉치의 문체 일치는 이 과제의 지렛대가 아닙니다.

추정 원인: 119 전사는 사람이 받아 적은 음성이라 맞춤법이 정상이고, 말버릇과
끊김은 있어도 어휘가 표준적입니다. KcELECTRA 가 학습한 네이버 댓글
(축약어·오타·신조어)과는 **다른 종류의 비격식**입니다.

# 48. 공식 Validation 실측 — 추정이 0.009 빗나갔습니다

ver4 의 fold 가중치를 확보해 같은 자로 비교했습니다.

| | 공식 Validation |
|---|---:|
| **제출 (이질 11개)** | **0.65658** |
| ver4, 0.5 + 보정 재적합 | 0.65591 |
| ver4, 증상별 임계값 | 0.65648 |

**정정 1**: 제 추정치는 0.648 이었는데 실측은 0.65658 입니다. Training 내부
홀드아웃(0.6467)이 공식 Validation 보다 **0.009 어려웠습니다**. ver4 도 같은
방향(내부 0.6597 → 0.6565)입니다. 홀드아웃을 Validation 예상치로 쓰면 안 됩니다.

**정정 2**: 처음에 ver4@0.5 를 0.65288 로 보고했는데, 그건 **임계값만 덮어쓰고
혼합 비율은 옛 임계값과 짝지어진 값을 그대로 둔** 결과였습니다. 보정을 0.5 에서
다시 맞추니 0.65591 로, 제약 비용이 −0.0036 에서 **−0.0006** 으로 줄었습니다.
"ver4 가 0.5 에 묶이자 무너졌다"는 제 서술은 틀렸습니다.

**정정 3**: 그래서 "ver4 를 0.5 로 재학습하면 더 오르지 않겠나"라는 질문의
답은 **거의 아니오**입니다. 임계값 제약이 남긴 비용이 0.0006 뿐이라, 재학습이
완벽히 회수해도 0.6565 로 제 점수와 같아집니다.
